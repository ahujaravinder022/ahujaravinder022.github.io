# Dr. Ravinder Ahuja — Academic Portfolio Website

Personal academic website built with HTML, CSS, and JavaScript. Hosted on GitHub Pages.

## 🚀 Deploy to GitHub Pages (5 steps)

### Step 1 — Create a GitHub repository

Go to [github.com/new](https://github.com/new) and create a repository named:

```
ravinderahuja
```

> Make it **Public**. This will host the site at `https://ahujaravinder022.github.io/ravinderahuja`

### Step 2 — Initialize git in this folder

Open a terminal/PowerShell in this folder (`ravinderahuja`) and run:

```bash
git init
git add .
git commit -m "Initial commit: academic portfolio website"
```

### Step 3 — Connect to GitHub and push

```bash
git remote add origin https://github.com/ahujaravinder022/ravinderahuja.git
git branch -M main
git push -u origin main
```

### Step 4 — Enable GitHub Pages

1. Go to your repository on GitHub
2. Click **Settings** → **Pages** (left sidebar)
3. Under **Source**, select branch: `main`, folder: `/ (root)`
4. Click **Save**

### Step 5 — Visit your site

After ~2 minutes, your site will be live at:
```
https://ahujaravinder022.github.io/ravinderahuja
```
